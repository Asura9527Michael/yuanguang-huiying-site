# 元光绘影传媒网站

公开页面：https://Asura9527Michael.github.io/yuanguang-huiying-site/

`index.html` 是从提供的 React + TypeScript + Vite 项目构建的独立发布文件，图片、样式与脚本均已内嵌。保持原有设计与内容。字体仍使用原项目 Google Fonts 链接，无法访问时使用系统备用字体。

`yuanguang-huiying-site.bundle` 保存提供的完整源码和 Git 历史，可用以下命令恢复：

```sh
git clone yuanguang-huiying-site.bundle
cd yuanguang-huiying-site
npm ci
npm run build
```

GitHub Pages 使用 main 分支根目录发布。更新 index.html 后自动重新发布。
